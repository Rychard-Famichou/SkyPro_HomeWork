# Проект обработки банковских операций
## Описание проекта

Проект предназначен для обработки списка банковских операций.

Он позволяет:

* Фильтровать операции по статусу (state)

* Сортировать операции по дате (date)

* Маскировать номера карт и счетов

Проект реализован на Python и состоит из модулей с функциями обработки данных.

## Цель проекта

Создать набор функций для:

- фильтрации операций по статусу выполнения,

- сортировки операций по дате,

- безопасного отображения номеров карт и счетов.

## Установка

1. Склонируйте репозиторий:

`git clone https://github.com/Rychard-Famichou/SkyPro_HomeWork.git`

2. Установите зависимости:

`poetry install`
